# Jogo-2D-Unity
Projeto desenvolvido na Unity como atividade acadêmica da disciplina de Desenvolvimento de Jogos Digitais.

## Sobre o Projeto
Este projeto consiste no desenvolvimento de um jogo 2D de plataforma utilizando a engine Unity e a linguagem C#.

## Funcionalidades
- Movimentação do personagem
- Sistema de pulo
- Animações
- Inimigos
- Coleta de itens
- Câmera dinâmica

## Tecnologias Utilizadas
- Unity 6
- C#
- Visual Studio
